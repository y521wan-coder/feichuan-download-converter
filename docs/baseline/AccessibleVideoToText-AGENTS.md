# 无障碍视频转文字项目规则

## 适用范围与优先级

本文件适用于 `D:\AccessibleVideoToMp3` 整个仓库。用户的明确指令优先于本文件；其后依次是本文件、`docs/requirements/最终开发计划.txt` 和现有代码约定。任何接手者在修改前必须完整阅读本文件、最终开发计划和 `交接说明.txt` 最后一个区块。

## 不可降低的产品边界

- 产品名称固定为“无障碍视频转文字”，目标系统为 Windows 10 IoT Enterprise LTSC 2021（19044）x64。
- 使用 C#、.NET 10 LTS、原生 WinForms 和标准控件。禁止 Electron、WebView、自绘列表、自定义标题栏、Canvas、图片按钮、隐藏焦点和依赖颜色或声音传达唯一信息。
- 第一版已有音频直转文字只支持 MP3；视频最终由 FFprobe 判断是否含可解码视频和音频流。
- 腾讯云只能使用常规录音文件识别 `16k_zh`。不得改用极速版、实时、一句话、语音流异步、大模型或任何默认收费增值能力。
- 源文件永不覆盖、移动或删除。输出必须先写 `.part`，成功后在同一卷原子提交；目标已存在时成对编号且永不覆盖。
- 核心无障碍项目未由争渡和纯键盘实测通过前，只能称为“测试候选版”，不能宣布完成。
- 公开发行前必须换为固定的 LGPL 兼容 FFmpeg 构建并完成许可证审计。当前本机 GPL nightly 只能用于开发验证，严禁复制到发布产物。

## GitHub 优先与开源合规

- 开发任何新功能前，先查询 GitHub 是否存在活跃、可复用、许可证兼容的实现。
- 在 `docs/research/开源复用评估.md` 记录项目地址、最近活跃度、许可证、Windows 10 19044 兼容性、键盘/无障碍风险和采用结论。
- 能安全复用时优先复用；不能复用时记录具体原因后再自行实现。
- 不得因复用界面引入自绘控件、隐藏焦点、Web UI 或许可证不明代码。
- 不复制没有明确许可证的代码，不逆向闭源软件。说明文字只能用于理解业务流程。
- 引入或升级依赖时固定确切版本，并同步更新第三方声明、许可证状态、测试记录和交接说明。

## 凭据、隐私与日志

- 任何已出现在聊天或历史记录中的 SecretId/SecretKey 均视为泄露，不得使用。
- 新凭据只允许从本地密码输入框获取，使用 DPAPI CurrentUser 加密，绝不写入源码、明文配置、日志、Git 或交接说明。
- 禁止提交密钥、签名 URL、用户媒体、识别正文、完整本地路径、运行日志和其他用户隐私。
- 日志中的文件只记录文件名或脱敏标识；异常文本写入前必须过滤密钥、授权头、签名查询参数和识别正文。
- 运行数据固定放在 `%LOCALAPPDATA%\AccessibleVideoToText`；不得放进程序目录。

## 架构与可测试性

- 保持 `IMediaProbe`、`IAudioConverter`、`ICloudObjectStore`、`ICloudTranscriber`、`IJobStore`、`ISettingsStore`、`IUsageLedger` 和 `IAccessibleStatusReporter` 职责分离。
- 任务阶段使用计划锁定的固定枚举，不以自由文本替代内部状态。
- 批次串行执行，单项失败后继续；网络重试仅限临时错误，等待 2、5、15 秒。
- 腾讯云请求参数必须有快照测试，确保大模型和增值参数不会被意外启用。
- UI 业务逻辑尽量下沉到可在无 UI 线程环境测试的服务；UIA 名称、角色、状态、值和焦点规则必须显式验证。

## 构建、测试与候选版

- 使用仓库内 `tools/dotnet` SDK。不要依赖或修改系统级 SDK。
- 所有构建、测试、发布命令从仓库根目录执行，并将结果写入 `logs/development` 的对应里程碑记录。
- 每个可测试版本必须先发布到版本化临时目录，完成单元、集成和启动冒烟测试后，才能更新 `artifacts/portable/current`。
- 更新 `current` 前确认旧测试程序没有占用文件；桌面快捷方式始终指向固定 `current` 目录并设置正确工作目录。
- 不得把“编译成功”等同于“无障碍通过”。没有争渡实测证据的项目标为“待测试”。

## Git 与交接

- 保持小而稳定的本地提交；提交前执行相关测试和秘密扫描。
- 不改写或删除已有交接历史。会话开始、重要里程碑和会话结束前，在 `交接说明.txt` 末尾追加完整区块。
- 交接区块必须包含版本、分支/提交、完成/进行/未完成、下一步准确操作、构建目录、快捷方式目标、测试结果、缺陷复现、依赖/许可证、非秘密腾讯云参数和可复制的接续说明。
- 工作区存在他人改动时必须保留；不使用 `git reset --hard` 或覆盖式恢复命令。
