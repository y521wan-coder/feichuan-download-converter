# 架构与安全基线

## 分层

- `AccessibleVideoToText.App`：WinForms 窗口、标准对话框、焦点恢复、UIA 状态通知。
- `AccessibleVideoToText.Core`：任务状态、队列、路径去重、输出命名、接口契约和纯业务规则。
- `AccessibleVideoToText.Infrastructure`：FFmpeg/FFprobe、DPAPI、JSON 持久化、腾讯云 ASR/COS、执行状态 API。
- `AccessibleVideoToText.Tests`：不依赖实际腾讯云费用的单元与集成测试。

依赖方向固定为 App → Core，App → Infrastructure，Infrastructure → Core。Core 不引用 WinForms、腾讯云 SDK 或 FFMpegCore。

## 运行数据

`%LOCALAPPDATA%\AccessibleVideoToText` 下规划：

- `settings.json`：普通设置，不含明文密钥。
- `credentials.dat`：DPAPI CurrentUser 加密结构。
- `jobs.json`：可恢复云任务检查点，不含签名 URL 和正文。
- `usage-ledger.json`：SecretId 不可逆哈希、北京时间月份、成功时长。
- `logs`：脱敏运行日志。
- `temp`：上传临时音频，任务结束尽力删除。

## 状态机

合法阶段：等待、探测、转换MP3、准备云端音频、上传、提交识别、云端识别中、写入TXT、清理、成功、部分成功、失败、已取消、待恢复。

终态必须解除“正在处理”全局锁、释放睡眠抑制、恢复按钮/关闭行为，并让焦点留在队列；这是状态同步约束，不由对话框 UI 临时推断。

## 云端固定参数

- API：CreateRecTask、DescribeTaskStatus
- 版本：2019-06-14
- Endpoint：asr.tencentcloudapi.com
- EngineModelType：16k_zh
- ChannelNum：1
- SourceType：0
- ResTextFormat：2
- ConvertNumMode：1
- FilterDirty：0
- FilterPunc：0
- FilterModal：1
- 增值项：全部显式关闭
- COS 区域：ap-shanghai

请求对象由一个集中工厂生成并进行快照测试，UI 不直接拼装参数。

## 输出事务

1. 在最终目标同目录预留成对可用基名。
2. 写入唯一 `.part.mp3` 或 `.part.txt`。
3. 刷新并关闭文件。
4. 最终路径仍不存在时执行同卷移动提交。
5. 失败或取消时删除 `.part`，绝不触碰源文件和既有目标。
