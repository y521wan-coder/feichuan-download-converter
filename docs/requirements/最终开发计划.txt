“无障碍视频转文字”完整开发与交接计划

一、项目目标与完成标准

在 D:\AccessibleVideoToMp3 新建独立项目，开发一个 Windows 10 x64 桌面软件，名称为“无障碍视频转文字”。

核心操作：

1. 在资源管理器复制一个或多个常见视频或 MP3。
2. 回到软件按 Ctrl+V。
3. 在标准无障碍确认窗口选择处理方式。
4. 按 Enter 立即开始：
   • 视频转 MP3；
   • 视频转 MP3 后上传腾讯云生成 TXT；
   • 已有 MP3 不重新编码，直接生成 TXT。
5. 结果保存完成后，在软件中读出成功、失败、保存位置和数量。

软件必须在 Windows 10 IoT 企业版 LTSC 2021、版本 19044、x64 上运行，并通过争渡读屏和纯键盘真实验收。当前电脑已经确认符合该系统版本，争渡已安装并正在运行。

核心无障碍项目任何一项失败，都只能标记为“待测试”或“有缺陷”，不能宣布完成。

二、项目目录、版本控制和长期交接

2.1 固定目录

项目根目录：

D:\AccessibleVideoToMp3

计划包含：

• src：程序源代码。
• tests：自动化测试和测试资源。
• tools：项目本地开发工具。
• third-party：FFmpeg、许可证和第三方声明。
• docs：需求、设计、测试记录、开源评估和快捷键说明。
• logs\development：构建、测试和开发记录。
• artifacts\portable\current：当前桌面测试版固定目录。
• artifacts\releases：保留的候选版本和校验值。
• AGENTS.md：后续所有 AI 和开发者必须执行的项目规则。
• 交接说明.txt：跨会话连续开发记录。
• docs\requirements\最终开发计划.txt：保存本计划的完整纯文本版本。

程序运行时产生的设置、加密凭据、待恢复任务和运行日志放在：

%LOCALAPPDATA%\AccessibleVideoToText

这是此前确认的例外：源代码、开发日志和交接资料在 D 盘项目内；最终用户的私有运行数据不放在程序目录。

2.2 交接说明底层规则

每次新会话开始、完成重要里程碑及会话结束前，都在 交接说明.txt 末尾追加一个完整区块，不覆盖历史内容。

每个区块必须包含：

• 日期时间和当前软件版本。
• 当前 Git 分支及提交编号。
• 已完成内容。
• 正在处理内容。
• 未完成内容和下一步准确操作。
• 最近构建目录。
• 桌面测试快捷方式目标。
• 已执行的测试及通过、失败项。
• 已知缺陷和复现步骤。
• 依赖版本和许可证状态。
• 腾讯云接口参数，但绝不记录 SecretId、SecretKey、签名URL或识别正文。
• 新会话可直接复制使用的接续说明。

每个稳定里程碑建立本地 Git 提交，禁止把密钥、用户媒体、识别正文和运行隐私提交到 Git。

2.3 GitHub 优先规则

把以下要求写进 AGENTS.md：

• 开发任何新功能前，先查询 GitHub 是否有活跃、可复用、许可证兼容的开源实现。
• 必须记录项目地址、活跃度、许可证、Windows 10 19044 兼容性、键盘和无障碍风险。
• 能安全复用时优先复用；不能复用时记录原因后再自行实现。
• 不允许因为复用开源界面而引入自绘控件、隐藏焦点或不明许可证。
• 不复制没有明确许可证的代码。
• 不逆向其他闭源软件。用户目前只有另一款软件的说明文字，没有其源代码，因此只借鉴业务流程。

已有评估结论：

• FFMpegCore 5.4.0：MIT，支持异步、进度和取消，选用。NuGet 项目页（链接）
• 腾讯云 .NET SDK：官方 Apache-2.0，选用 ASR 独立包。
• TencentCloudSDK.Asr 3.0.1442：固定版本。NuGet 项目页（链接）
• Tencent.QCloud.Cos.Sdk 5.4.51：用于 COS，固定版本。NuGet 项目页（链接）
• ffmpeg_batch：界面复杂、无障碍风险较高，不直接改造。
• Audio-Converter：存在主动隐藏焦点提示的控件且许可证不清，不复用。
• extract-audio-tracks-from-video：可参考简单流程，但缺少批量、进度和取消。
• Axiom：旧 WPF/GPL 项目，不适合闭源发布。

三、技术架构与许可证

3.1 桌面技术栈

• C#、.NET 10 LTS、原生 WinForms。
• 发布为 win-x64 自包含版本，不要求用户预装 .NET。
• .NET SDK 安装在项目本地，不修改系统级开发环境。
• 使用原生 WinForms 控件和 UI Automation。
• 不使用 Electron、WebView、自绘列表、自定义标题栏、Canvas 或图片按钮。
• .NET 10 官方支持 Windows 10 21H2 LTSC/Enterprise x64，覆盖目标系统。Microsoft 支持表（链接）

3.2 FFmpeg

开发期间可以使用本机现有 FFmpeg GPL nightly 验证功能，但不得把它放进未来闭源公开发行包。

公开发布前必须换为：

• 固定版本的 LGPL 兼容 FFmpeg x64 构建。
• 不启用 GPL 或 nonfree 组件。
• FFmpeg 作为独立进程调用，不静态链接进应用。
• 附完整 LGPL 文本、FFmpeg 源码地址、确切版本和构建配置。
• 在 Windows 10 19044 实机重新测试，不采用只保证 Windows 10 22H2 的构建作为唯一发行文件。

3.3 内部接口与任务状态

第一版没有对外公开 API、命令行接口、账号接口或服务器接口。

内部按以下职责分离：

• IMediaProbe：FFprobe 获取格式、时长、音轨和元数据。
• IAudioConverter：视频转最终 MP3、生成云端上传临时音频。
• ICloudObjectStore：COS 建桶、生命周期、上传、签名URL和删除。
• ICloudTranscriber：提交、查询、解析腾讯云 ASR 任务。
• IJobStore：保存待恢复任务和任务检查点。
• ISettingsStore：普通设置和 DPAPI 凭据。
• IUsageLedger：本机每月识别时长估算。
• IAccessibleStatusReporter：通过标准控件状态和 UIA 事件报告变化。

任务阶段固定为：

等待、探测、转换MP3、准备云端音频、上传、提交识别、云端识别中、写入TXT、清理、成功、部分成功、失败、已取消、待恢复

四、主界面和无障碍交互

4.1 主窗口

使用标准菜单、ListView 或 ListBox、按钮、标签、进度条、组合框、单选按钮、复选框和标准对话框。

主要区域：

1. 菜单栏。
2. 文件队列。
3. 当前任务状态和文本进度。
4. 操作按钮。
5. 可重新查看的批次结果区域。

每个队列项目报告：

• 文件名，不在读屏和日志中自动朗读完整路径。
• 文件类型。
• 当前状态。
• 当前步骤。
• 是否选中。
• 项目位置和总数。
• 成功、失败或部分成功结果。

焦点规则：

• 启动后焦点位于文件队列或可立即接收 Ctrl+V 的主区域。
• 对话框打开后读出标题，焦点落到默认操作。
• 对话框关闭后返回触发位置。
• 删除队列项目后移动到相邻项目。
• 批次结束后留在队列；有失败时聚焦第一个失败项目。
• 不自动打开文件或文件夹。
• 不为朗读消息随意抢焦点。

主要快捷键：

• Ctrl+V：粘贴资源管理器中的文件。
• Ctrl+O：标准打开文件对话框。
• Delete：只从队列移除，不删除磁盘文件。
• Alt+S：设置。
• Alt+O：选择或打开结果目录。
• F1：键盘和云端帮助。
• Esc：取消对话框；任务中打开取消范围对话框。
• 所有快捷键同时提供菜单或按钮入口。

4.2 粘贴确认窗口

只粘贴视频：

• “仅转换 MP3”为默认项。
• “转换 MP3 并用腾讯云生成 TXT”。
• Enter 开始，Esc 取消。

只粘贴 MP3：

• 默认“用腾讯云生成 TXT”。
• 不重新生成最终 MP3。
• Enter 开始，Esc 取消。

视频和 MP3 混合：

• 读出视频数、MP3数和跳过数。
• 视频处理方式使用标准单选按钮。
• “同时识别现有 MP3”默认选中。
• 多文件范围提供“转换全部、仅转换第一个、取消”。
• “转换全部”为默认按钮；一次 Enter 后立即开始。

队列规则：

• 最多一次粘贴 100 个有效文件；超过时整批拒绝并说明。
• 保持剪贴板顺序。
• 用规范化完整路径去重，保留第一次出现，报告重复数。
• 文件夹、图片等无效项目跳过并报告。
• 正在处理时新粘贴会被拒绝并读出原因。
• 上一批已结束时，新粘贴自动清空旧队列，但不删除输出文件或历史日志。
• 本地、U盘、移动硬盘和 UNC 网络共享路径均支持。

4.3 进度与取消

• 进度文本紧邻进度条并位于操作按钮上方，争渡可用逐行阅读找到。
• 本地转换和 COS 上传显示可确定进度，按约 5% 节制更新。
• 腾讯云识别没有真实百分比，只显示“腾讯云识别中，已等待……”，不伪造百分比。
• 主动朗读仅限阶段开始、完成、失败和需要操作，避免不断打断争渡。
• 不使用动画、颜色或声音作为唯一信息。
• Esc 在任务中打开：
  • 跳过当前并继续；
  • 停止整个批次；
  • 继续处理，默认焦点在这里。
• 已提交的腾讯云任务无法取消，必须明确说明仍可能继续并占用额度。

五、视频与 MP3 处理

5.1 视频支持范围

不限制为 MP4，至少覆盖常见：

• MP4、MKV、MOV、AVI、WMV。
• FLV、WebM、M4V。
• MPEG、MPG。
• TS、M2TS。
• 3GP。

处理规则：

• 常见扩展名只作初筛。
• 最终用 FFprobe 判断是否为视频、是否有音轨及是否可解码。
• 未知扩展名但实际包含可解码视频和音频流时可以接受。
• 无音轨、文件损坏或编解码器不支持时给出具体错误。
• 多音轨视频固定使用第一条音轨并在任务详情中报告。
• 第一版对“已有音频直接转 TXT”只接受 MP3；其他纯音频格式不自动扩大范围。

5.2 最终 MP3

• FFmpeg 后台进程隐藏控制台窗口。
• 输出 CBR 恒定码率。
• 可选 128、192、256、320 kbps，默认 192 kbps。
• 尽量保持原音频采样率和声道布局。
• 保留兼容的标题、艺术家、专辑等文字元数据。
• 跳过不兼容标签，不把视频画面作为封面。
• 源文件只读，永不覆盖、移动或删除。
• 先写 .part.mp3，成功后原子改名。
• 同名文件自动使用 文件名 (1).mp3、文件名 (1).txt，MP3和TXT编号保持一致，永不覆盖。

视频超过腾讯云 5 小时限制时：

• 仍生成完整 MP3。
• 不提交云识别。
• 报告“MP3成功、TXT因超过官方时长限制未生成”。
• 不自动切段，避免产生多任务和额外费用。

5.3 现有 MP3

• 原 MP3 不重新编码、不修改。
• 只生成临时的 16kHz、单声道、64kbps CBR MP3 上传副本。
• TXT 默认保存在原 MP3 旁边。
• 原目录不可写时，使用标准文件夹对话框选择备用目录。
• 一批文件只询问一次备用目录。
• 临时上传副本在任务结束后删除。

5.4 TXT

• 只写可以直接阅读的连续正文。
• 不加入标题、文件名、时间戳、任务编号、说话人编号、时长或技术信息。
• 保留标点，按自然语句连续排版，不强制每句一行。
• 智能转换阿拉伯数字，例如“第一百二十三”按语境转为 123。
• 保留脏话和敏感词，不替换星号。
• 过滤部分明显语气词，但不启用付费“口语转书面语”。
• UTF-8 BOM 编码、Windows CRLF 换行。
• 先写 .part.txt，完成后原子改名。
• 没有有效语音时标记失败，不生成空 TXT。
• 云端失败时保留已经成功生成的 MP3。
• 提供“只重试 TXT”操作，不重新转换源视频。

六、腾讯云标准录音文件识别

6.1 固定服务与参数

必须使用标准“录音文件识别”，绝不使用：

• 录音文件识别极速版。
• 实时语音识别。
• 一句话识别。
• 本地语音识别。
• 语音流异步识别。
• 大模型1.0或2.0引擎。
• 情绪识别、说话人分离、付费语义分段或口语转书面语。

官方当前确认普通录音文件识别有每月 10 小时免费额度，而大模型1.0和2.0免费额度为“无”，因此固定使用常规 16k_zh。腾讯云现行计费表（链接）

固定请求：

• API：CreateRecTask、DescribeTaskStatus。
• API版本：2019-06-14。
• 域名：asr.tencentcloudapi.com。
• EngineModelType=16k_zh。
• ChannelNum=1。
• SourceType=0，使用签名 COS URL。
• ResTextFormat=2，取得带标点的详细结果，但最终只输出正文。
• ConvertNumMode=1。
• FilterDirty=0。
• FilterPunc=0。
• FilterModal=1。
• 所有增值参数明确关闭。
• 从结果详情提取句子正文并连续合并，丢弃时间戳等结构信息。

腾讯云标准接口当前限制为 URL 音频最长 5 小时、最大 1GB，结果保留约 24 小时。录音文件识别接口（链接）

6.2 COS

首次真正选择云端转 TXT 时启动配置流程：

• 用户输入 AppID、SecretId、SecretKey。
• 使用专门创建的最小权限 CAM 子账号。
• 区域固定上海 ap-shanghai。
• 软件创建私有、标准存储、不开版本控制的专用存储桶。
• 基础名称：accessible-video-to-text-{AppID}。
• 名称冲突时添加随机后缀，并记住实际名称。
• 对象使用随机 GUID 名称，不上传原始文件名。
• 只在应用专用前缀操作，不碰用户其他 COS 文件。
• 成功或最终失败后立即删除云端对象。
• 专用前缀配置 1 天生命周期，并清理未完成分块上传，作为异常退出兜底。
• 生命周期删除也可能产生少量 COS 请求费用，首次配置时明确说明。腾讯云生命周期说明（链接）

6.3 凭据安全

用户先前发到聊天里的 SecretId 和 SecretKey已经公开暴露，必须在腾讯云控制台撤销并重新创建，旧值不得进入项目。

新凭据：

• 只能由用户在软件的密码输入框中本地填写。
• 默认隐藏，必须明确操作才能暂时显示。
• 使用 Windows DPAPI CurrentUser 加密。
• 不写源代码、配置明文、日志、Git或交接说明。
• 每台电脑必须重新输入，因为 DPAPI 数据不可跨电脑复制。
• 日志不记录签名URL、密钥、完整本地路径或识别正文。

“清除本机全部数据”需要两次明确确认，删除设置、加密凭据、使用量估算、日志和任务记录。存在待恢复云任务时禁止直接清除，必须先处理或明确结束任务恢复状态。

6.4 免费额度和费用保护

• 首次配置显示完整隐私、ASR收费、COS收费和后付费风险说明。
• 以后每批只显示将上传腾讯云、本批估算时长和本机月累计。
• 本机按 SecretId 不可逆哈希和北京时间自然月记录成功识别时长。
• 本机估算达到或超过 10 小时时，提交前单独确认，默认取消。
• 用户明确选择“仍然提交”才能继续。
• 本机无法知道其他电脑、其他软件或控制台产生的使用量，始终说明腾讯云控制台是唯一权威数据。
• 腾讯云配置只保存，不自动提交测试音频，不消耗测试额度。

七、任务可靠性、网络和后台运行

7.1 顺序和错误隔离

• 一批任务串行处理，降低资源和费用风险。
• 单项失败后记录原因并继续下一项。
• 批次结束读出成功、部分成功、失败和跳过数量。
• 网络、认证、权限、空间、源文件消失、输出不可写分别给出可操作错误。
• 使用 Windows 系统网络和代理设置，不自带代理配置。

临时网络错误重试三次：

• 第一次等待 2 秒。
• 第二次等待 5 秒。
• 第三次等待 15 秒。

认证失败、权限不足、额度耗尽、参数错误和文件超过限制不重复重试。

7.2 云端任务恢复

• 每 5 秒查询一次正常识别状态。
• 窗口开启时一直跟踪，直到成功、明确失败或超过约24小时有效期。
• 保存 TaskId、对象键、提交时间、输出目标和当前阶段。
• 异常退出、关机或重启后，启动时弹出待恢复任务汇总：
  • 全部继续查询，默认；
  • 暂不处理；
  • 查看详情。
• 腾讯云没有提交后取消接口，关闭软件不能宣称云任务已取消。
• 清理 COS 失败时，TXT结果仍可标记成功，但显示云端清理警告并保留重试清理记录。

7.3 睡眠和托盘

有转换、上传或云任务跟踪时：

• 使用 Windows 执行状态 API 临时阻止系统自动睡眠。
• 允许屏幕按原策略关闭。
• 任务结束、暂停或退出后立即恢复系统原策略。

托盘行为：

• 最小化时隐藏到系统托盘继续运行。
• 任务进行中按 Alt+F4 或关闭按钮，直接隐藏到托盘。
• 使用标准可访问托盘图标名称说明当前状态。
• 不设置全局快捷键，避免与争渡冲突。
• 恢复路径：Win+B，方向键找到“无障碍视频转文字”，Enter。
• 托盘菜单提供“显示主窗口”和“退出软件”。
• 空闲时 Alt+F4 直接退出，不残留托盘进程。
• 后台完成时不弹通知、不播放声音，只更新托盘可访问名称和状态。
• 任务中从托盘退出必须详细确认，默认“返回继续”；明确退出后停止本地任务并保存已提交云任务。

八、构建、桌面快捷方式和测试循环

8.1 测试版发布

每个可测试版本：

1. 编译到版本化临时目录。
2. 运行单元测试、集成测试和启动冒烟测试。
3. 确认旧测试版程序没有占用文件。
4. 更新 artifacts\portable\current。
5. 创建或更新桌面快捷方式：
   • 名称：“无障碍视频转文字（测试版）”。
   • 桌面：C:\Users\apple007\Desktop。
   • 始终指向固定 current 目录。
   • 工作目录设置为程序目录。
6. 从桌面快捷方式实际启动一次验证。
7. 更新 交接说明.txt，再通知用户测试。

以后按以下循环迭代：

生成测试版 → 用户从桌面快捷方式测试 → 记录准确复现步骤 → 修复 → 自动回归 → 争渡回归 → 更新同一快捷方式目标

8.2 自动测试

至少包括：

• Clipboard FileDrop 读取、顺序、去重和100项限制。
• 常见视频格式探测及无音轨、损坏文件。
• 第一音轨选择。
• CBR 128/192/256/320 MP3。
• 元数据保留和不嵌入封面。
• 同名成对编号及 .part 原子提交。
• 视频、MP3和混合粘贴流程。
• 不可写目录备用保存。
• UNC断开、文件消失和磁盘空间不足。
• 单项失败后继续。
• 任务取消三个分支。
• 腾讯云请求参数快照，确保没有大模型或增值参数。
• 网络重试和不可重试错误分类。
• 任务持久化、异常退出和恢复。
• 24小时过期。
• COS对象即时删除和1天生命周期规则范围。
• DPAPI加解密及日志秘密扫描。
• TXT编码、CRLF、正文清理、空识别失败。
• 本机10小时估算和跨月归零。
• 清除本机数据的双重确认与待任务保护。

8.3 格式兼容测试

至少准备短小、无版权或自行生成的测试文件：

• MP4/H.264、MKV、MOV、AVI、WMV、FLV、WebM、MPEG、TS、M2TS、3GP。
• 单声道、立体声、多音轨。
• 无音轨视频。
• 损坏文件和伪造扩展名。
• 中文、空格、括号、超长路径和非常规字符文件名。
• 本地磁盘、移动存储和 UNC 路径。
• 现有 MP3。
• 超过5小时用模拟元数据或受控长样本验证分支，不实际提交云端。

8.4 无障碍强制验收

在 Windows 10 IoT Enterprise LTSC 19044 x64、争渡开启、只用物理键盘完成：

• 从桌面快捷方式启动。
• 听清窗口标题、队列、按钮、设置和状态。
• Tab、Shift+Tab、方向键、Enter、空格和Esc。
• Ctrl+V 导入单个、多文件和混合文件。
• 完成 MP3、MP3加TXT及已有MP3转TXT。
• 操作所有菜单、设置、确认、错误和取消窗口。
• 验证进度、成功、失败和等待状态。
• 验证弹窗关闭后的焦点返回。
• 验证任务完成后队列焦点。
• 验证最小化托盘、Win+B恢复和任务中退出确认。
• 验证高对比度、125%和150%缩放。
• 验证无需鼠标、OCR、模拟鼠标、标签或争渡专用朗读API。
• 使用 UIA 检查名称、角色、状态、值、焦点和事件。
• 用户完成一轮真实使用验收前，只能称为“测试候选版”。

十一、已锁定假设

• 软件名称：“无障碍视频转文字”。
• 项目目录：D:\AccessibleVideoToMp3。
• 当前只开发 Windows x64 桌面版。
• 视频格式不限 MP4，以 FFmpeg 实际可解码能力为准。
• 现有音频直转文字第一版只支持 MP3。
• 腾讯云固定使用具有每月10小时免费额度的常规录音文件识别 16k_zh。
• 不提供无免费额度的大模型引擎。
• COS是腾讯云远程处理中转，不是本地语音识别。
• 当前已泄露的腾讯云密钥必须撤销，开发和测试只能使用新密钥。
• 没有未解决的高影响产品选择；后续若官方计费、API限制或Windows兼容性发生变化，必须暂停相关实现、重新核验并写入交接说明，不能自行改变收费档或降低无障碍要求。
