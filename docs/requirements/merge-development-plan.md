## 仓库与产品

- 在 `D:\FeichuanDownloadConverterDev` 建立独立 Git 仓库；两个旧项目保持原样，作为稳定
  基线。
- 产品名称固定为“飞船下载转换工具”，显示版本和安装包版本为 `1.0`，内部程序集版本
  使用 `1.0.0.0`。
- 保留飞船全部下载能力和原视频转 MP3、腾讯云转 TXT 能力，不重写下载算法，不新增无关
  功能。
- 建成一个原生 WinForms 主窗口；下载内核作为不可见 Python 后台进程运行。界面与下载、
  转换、云端状态全部在同一主窗口显示。
- 继续暂停服务器更新发布，只制作本地安装包。

## 统一界面与操作流程

- 启动后焦点固定在“下载链接或平台分享文本”输入框，不弹出更新检查，也不自动跳到其他
  区域。
- 输入框之后的第一个 Tab 位置是标准组合框，固定包含“只下载”“下载后转换为 MP3”
  “下载、转换 MP3 并生成 TXT”“获取解析直连”。只下载是启动和每次任务结束后的默认值。
- 在输入框或组合框上按 Enter 均可开始；上下光标选择模式。
- Ctrl+V 根据剪贴板真实格式分流：文本或分享链接进入原飞船下载流程；资源管理器 FileDrop
  进入原本地文件队列及确认窗口，保留顺序、去重、100 项限制和混合 MP4/MP3 规则。
- 下半部分使用两个标准页签“任务队列”和“状态与日志”；程序不得自行抢焦点或切换页签。
- 保留下载文件夹、品质选择、抖音专用登录、清除登录、手动检查软件更新、手动检查下载
  核心更新、帮助、打赏和所有原确认窗口。
- 单链接按顶部模式自动衔接；主页、合集、频道和播放列表下载完成后，再确认是否开始后续
  处理。
- “获取解析直连”接受单视频和单条抖音图文，不下载媒体；视频优先复制音画合一直连，只有
  分轨时复制音频直连；图文固定复制背景音频直连。地址由 worker 直接写入系统剪贴板，
  不经过协议、日志或磁盘。
- 混合结果中视频转 MP3，已有 MP3 不重新编码并可直接转 TXT，图片和不支持的音频格式
  保留下载结果并明确标为跳过。
- 下载文件永不删除或覆盖；MP3/TXT 继续使用 `.part`、原子提交和成对编号。后续失败只能
  形成“下载成功、转换或 TXT 失败”的部分成功结果。
- 腾讯云流程保留凭据检查、精确时长/费用确认、COS 临时上传、任务恢复和对象删除，不因
  选择一条龙而绕过确认。
- `Alt+O` 打开当前任务结果目录：下载任务对应下载文件夹，转换任务对应 MP3/TXT 目录。
- 普通最小化进入任务栏。任务中关闭或 Alt+F4 显示“转入托盘继续（默认）”“取消任务并
  退出”“返回软件”；空闲时 Alt+F4 直接退出。
- “只重试 TXT”“自选统一结果目录”“明确结束恢复状态”等旧待办不在本次合并范围内。

## 技术实现与安全边界

- 使用 .NET 10 WinForms 建立统一外壳，复用现有转换项目的 Core、Infrastructure、DPAPI、
  腾讯云和安全输出代码。
- Python 下载代码保持独立内核，通过 PyInstaller 构建 `feichuan-worker.exe`；移除 wxPython
  界面依赖，保留下载协调器、抖音浏览器抓流、YouTube、yt-dlp、更新核心和下载状态逻辑。
- WinForms 与下载内核采用版本化 JSON Lines 标准输入/输出协议，并异步读取 stdout/stderr。
- 协议覆盖握手、链接识别、扫描、确认选择、品质查询、下载进度、结果路径、取消、下载
  目录设置、抖音登录状态、核心更新和软件更新。
- 扫描得到的 Cookie、签名地址、媒体令牌和浏览器上下文只在 Python 内存中，以临时操作
  ID 引用；不得进入 JSON 消息、日志或磁盘。
- worker 异常时给出可操作错误并允许重新扫描；正常取消失败时才终止整个进程树。
- 两套运行数据直接兼容、不迁移或解密：`%LOCALAPPDATA%\FeichuanDownloader` 与
  `%LOCALAPPDATA%\AccessibleVideoToText`。
- 现有 `credentials.dat` 只能由合并应用通过 DPAPI CurrentUser 使用；不得读取、显示或导出
  SecretId/SecretKey。
- 共用飞船现有固定 LGPL 3 FFmpeg/ffprobe，不携带旧 GPL nightly；统一许可证、版本和
  SHA-256 清单。
- 软件更新继续使用 `product_key=feichuan_download_tool`、Windows/stable 和服务器返回的
  `download_url`，但只允许手动检查，本次不发布服务器版本。
