无障碍视频转文字 0.1.0 测试候选版

本版本只用于当前电脑的功能和无障碍测试，不是公开发行包。

已实现：
1. Ctrl+V 或 Ctrl+O 添加视频和 MP3。
2. 常见视频探测、第一音轨转换、128/192/256/320 kbps CBR MP3。
3. 腾讯云新凭据 DPAPI 加密、私有 COS、常规 16k_zh 录音文件识别、TXT 正文输出、用量估算、任务恢复和云端清理。
4. 原生 WinForms 标准控件、键盘操作、取消范围、托盘和防自动睡眠。

重要边界：
- 云端功能必须在软件设置窗口填写已经重新创建的新凭据。聊天中曾出现的旧凭据已经暴露，必须撤销，禁止使用。
- 配置凭据本身不会上传测试音频；每批提交前会再次说明费用。
- 本测试包不含 FFmpeg。当前开发电脑使用系统 PATH 中已有的 GPL nightly，仅限本机验证，禁止复制或公开分发。
- 争渡、纯键盘、高对比度和缩放强制验收尚待用户实测，因此本版本只能称“测试候选版”。
