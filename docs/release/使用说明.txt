飞船下载转换工具 1.0 使用说明

一、开始使用

1. 启动后焦点在“下载链接或平台分享文本”输入框。粘贴普通链接或完整分享文本，在输入框、处理模式或图文下载内容组合框按 Enter 开始。
2. 处理模式按顺序为：只下载；下载后转换为 MP3；下载、转换 MP3 并生成 TXT；获取解析直连。后面是“图文下载内容”，可选“仅下载音频”或“下载图片和音频”。程序启动和每次任务结束后分别恢复为“只下载”和“仅下载音频”。
3. Ctrl+V 会读取剪贴板的真实格式。文本进入链接下载流程；从资源管理器复制的 FileDrop 文件进入本地队列和确认窗口。文件保持原顺序，规范路径去重，单批最多 100 项。
4. 任务队列和状态与日志是两个标准页签。程序不会自行切换页签或抢走焦点。

二、下载、转换和输出

1. 单链接按顶部模式自动衔接。主页、合集、频道或播放列表先下载；已选择生成 TXT 时自动继续上传识别，只转 MP3 的批量后处理仍保留原确认。
2. 混合结果中，视频以及 M4A、AAC、FLAC、WAV、OGG、Opus、WMA 等纯音频可转换为 MP3；已有 MP3 不重新编码，可直接生成 TXT；图片保留下载结果并标记为跳过。
3. 下载源文件永不删除、移动、覆盖。MP3/TXT 先写临时 .part 文件，成功后原子提交；同名输出按成对编号保存，绝不覆盖。
4. 后续转换或云端失败时，已下载文件仍保留，结果会明确显示“下载成功、转换或 TXT 失败”。
5. Alt+O 打开当前任务结果目录：下载任务是下载文件夹，转换任务是 MP3/TXT 所在目录。
6. 选择“获取解析直连”后按 Enter，可解析一个视频或一条抖音图文，不下载或创建媒体文件。视频优先把最佳音画合一直连复制到系统剪贴板，原站只有音视频分轨时只复制最佳音频直连；抖音图文固定复制背景音频直连，不受“图文下载内容”选项影响。主页、合集、频道、播放列表和直播不支持此模式。直连可能短期失效，请及时使用。
7. 按 Alt+S 打开设置，在“生成文件位置”中可保留默认的“源文件旁边”，也可选择“统一保存到指定文件夹”。统一目录只影响新生成的 MP3/TXT，不移动历史结果，不改变下载文件夹，也不复制或改写现有 MP3。统一目录失效或不可写时，本批会在开始前停止并要求重新选择，不会偷偷改存到其他目录。
8. 下载微信小鹅通已购课程：先在微信内置浏览器打开自己已购买的课程目录或其中一节回放，再按 Alt+W。软件会报出当前课程名、课程页已更新数量和其中的直播视频数量，确认后只逐节打开这个目录中的“直播”回放；图文、推荐课程和其他页面内容不会下载。已有同名视频必须通过音视频轨道校验后才会跳过，所以以后再次运行同一课程可只补新发布的课程。课程名写有计划讲数，但尚未出现在已购目录中的内容不能提前下载。采用加密或 DRM 保护的课程会安全拒绝，不会尝试破解。

三、抖音、品质和更新

1. 抖音需要登录时，只使用软件的“抖音专用登录”。它使用独立浏览器资料，不读取日常浏览器 Cookie；“清除登录”只清除该专用资料。
2. 品质可选最高品质或每次询问；具体可选项以当前资源实际提供的格式为准。
3. 软件和下载核心都不会在启动时自动检查更新。只能通过菜单手动检查。
4. 抖音单条图文默认仍只下载背景音频。主动选择“下载图片和音频”时，软件从作品详情下载全部作品原图并统一保存为 WebP，同时下载背景音频；不会抓取头像、二维码、推荐内容或页面图标，也不会对图片做 OCR、转换 MP3 或语音识别。若处理模式要求生成 TXT，只处理背景音频。

四、取消、关闭、托盘和错误恢复

1. Esc 或“取消任务”打开取消范围。按窗口说明选择跳过当前项目、停止整个批次或返回继续。
2. 普通最小化只进入任务栏。任务中关闭或按 Alt+F4 会出现三个选项：“转入托盘继续（默认）”“取消任务并退出”“返回软件”。空闲时 Alt+F4 直接退出。
3. Win+B 可进入通知区域，找到“飞船下载转换工具”并按 Enter 恢复窗口。
4. worker 崩溃会显示可操作错误。请先重新扫描；正常取消无响应时软件才会终止整个 worker 进程树，避免残留 yt-dlp、FFmpeg 或专用 Chrome。
5. 云端任务已提交后即使本地取消，腾讯云仍可能继续并消耗额度；软件会保存待恢复记录，下次启动可继续查询和清理。

五、快捷键

Ctrl+V：粘贴链接/分享文本，或粘贴资源管理器 FileDrop 文件。
Ctrl+O：用标准文件对话框添加本地视频或音频。
上下方向键：在处理模式或图文下载内容组合框选择模式。
Enter：在链接输入框、处理模式或图文下载内容组合框开始。
Delete：只从队列移除，不删除磁盘文件。
Alt+S：设置。
Alt+O：打开当前任务结果目录。
Alt+W：读取并下载微信当前打开的小鹅通已购课程；确认窗口默认不开始。
小键盘 8：任务进行中，窗口标题会持续包含最近的当前百分比。争渡截获小键盘 8 并朗读当前窗口时，会读出这个百分比；其他读屏软件若把按键交给本软件，也会收到一次进度通知。Num Lock 开关均可使用，仅在软件窗口处于前台时生效。
F1：重新打开本使用说明。
Esc：任务中打开取消范围；普通对话框中返回。
Alt+F4：空闲时退出；任务中打开三选项关闭窗口。
Win+B：进入通知区域并恢复托盘中的软件。

六、腾讯云账号、密钥和最小权限

1. 日常使用建议创建 CAM 子用户，不使用主账号永久密钥。在访问管理控制台创建可编程访问子用户，并通过自定义策略只授权本软件需要的操作。官方说明：https://cloud.tencent.com/document/product/598/37140
2. 最小权限应只覆盖常规录音文件识别 CreateRecTask、DescribeTaskStatus，以及应用专用 COS 存储桶/前缀所需的建桶、查询、生命周期、上传、读取签名和删除对象操作。不要授予其他云产品、财务管理或全账号管理权限；控制台策略名称和动作以腾讯云当前页面为准。
3. AppID 可在腾讯云账号信息中查看。SecretId 与 SecretKey 是 API 身份凭据；SecretKey 只在创建时显示，必须当场妥善保存。不要把密钥发到聊天、邮件、日志或交接说明。
4. 在软件中按 Alt+S，选择配置腾讯云凭据，只在本机密码输入框填写 AppID、SecretId、SecretKey。软件使用 Windows DPAPI CurrentUser 加密保存到当前 Windows 用户，不能跨电脑复制使用。
5. 怀疑泄露时立即在 CAM 禁用并删除旧密钥，创建新密钥后只在软件内更新。

七、开通 ASR、额度和费用

1. 首次使用前进入语音识别控制台，阅读服务条款，勾选同意并开通服务。官方步骤：https://cloud.tencent.com/document/product/1093/104735
2. 本软件固定使用普通录音文件识别 16k_zh，不使用极速版、大模型、实时、一句话、说话人分离、情绪、语义分段或口语转书面语等收费增值能力。
3. 截至 2026-08-10，官方计费说明列出普通录音文件识别每月 10 小时免费额度；2022 年 5 月起新用户默认关闭后付费，此前的老用户应自行核对后付费状态。额度、价格和规则可能变化，以官方页面为准：https://cloud.tencent.com/document/product/1093/35686
4. 选择生成 TXT 后，软件自动继续上传腾讯云和识别，不再弹出是/否确认。提交前仍按精确媒体时长显示本批和本机本月用量估算，达到原 10 小时参考线也按所选任务继续。其他电脑、控制台或软件的用量无法由本机准确得知，腾讯云控制台是权威数据。
5. 资源包、剩余额度和失效记录：进入语音识别控制台的“资源包管理”。官方说明：https://cloud.tencent.com/document/product/1093/54408
6. 官方产品和购买入口：https://cloud.tencent.com/product/asr ；账单请在腾讯云费用中心查询。

八、COS 临时音频与隐私

1. 生成 TXT 时，软件把临时音频上传到您自己的上海区域私有 COS 专用桶，使用随机对象名和应用专用前缀；提交 ASR 后轮询结果。
2. 成功或最终失败后立即请求删除 COS 对象；专用前缀同时设置 1 天生命周期和未完成分块清理。删除失败会保留待恢复记录，不能保证云端瞬时清除。
3. COS 上传、存储、删除和生命周期操作可能产生少量请求费用。官方请求费用说明：https://cloud.tencent.com/document/product/436/53861
4. 凭据、Cookie、授权头、签名 URL、媒体令牌、浏览器上下文和识别正文不会写入普通日志、Git 或交接说明。worker 协议只传递非敏感元数据和临时操作 ID。“获取解析直连”是用户明确要求的例外输出：地址只在 worker 内存中解析并写入当前 Windows 用户的系统剪贴板，不经过协议、日志或磁盘。微信小鹅通功能只读正在播放时产生的 Chromium HTTP 缓存键，不读取 Cookie、浏览历史或本地存储；临时 HLS 地址仍只留在 worker 内存。
5. 两套旧运行数据继续直接兼容，不迁移或解密：%LOCALAPPDATA%\FeichuanDownloader 与 %LOCALAPPDATA%\AccessibleVideoToText。

九、当前范围

“自选统一结果目录”已进入离线优先接续开发；“只重试 TXT”和“明确结束恢复状态”仍按离线优先计划分阶段实现。需要真实腾讯云、下载平台或更新服务器的新增行为只保留接口，未经用户以后明确要求不会自动执行。无障碍自动化通过后仍只称测试候选版，直到用户以后完成争渡朗读验收。

十、任务结束提示音与自行替换

1. 下载、转换、生成 TXT、解析直连、微信课程下载和恢复查询结束后，会播放一次短提示音；下载和后处理组成的整项任务只响一次。提示音表示本机任务已结束，成功、失败或取消请以界面结果为准。
2. 提示音文件位于软件安装目录，名称固定为“任务结束.wav”。本机当前完整路径：C:\Users\apple007\AppData\Local\Programs\飞船下载工具\任务结束.wav。其他电脑请打开软件所在文件夹查找同名文件。
3. 先退出软件，再把喜欢的音效转换为普通 PCM WAV，改名为“任务结束.wav”并替换同名文件；重新打开软件后生效。建议使用简短音效。不能仅把 MP3 扩展名改成 WAV。
4. 覆盖安装会保留已经存在的同名提示音。文件缺失、损坏或不能读取时，会使用程序内置的默认提示音，任务处理不受影响。
